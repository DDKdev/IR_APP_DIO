# 📊 IR App

Aplicativo para organização dos dados do **Imposto de Renda (IR)**, desenvolvido **totalmente no Excel**, sem necessidade de instalar nenhum programa adicional.

## Sobre o projeto

O IR App reúne em uma única planilha, de forma guiada, as informações necessárias para a declaração do Imposto de Renda de pessoa física. A navegação é feita por botões (**Próximo** / **Anterior**), passo a passo, como em um aplicativo.

## Estrutura

| Aba | Etapa | O que faz |
|---|---|---|
| **TITULAR** | 1. Dados do titular | Cadastro dos dados pessoais: nome, CPF, nascimento, título de eleitor, endereço, contato e situação (cônjuge, dependentes, residência no exterior). |
| **NOTAS** | 2. Notas bancárias ou extratos | Registro das entradas mês a mês, com data, categoria e valor. |
| **INFORMES** | 3. Informes de rendimento | Lista os rendimentos de todos os bancos, com o valor de cada um, o anexo do informe e o total consolidado. |

## Como usar

1. Abra o arquivo `IR_app.xlsx` no Excel.
2. Comece pela aba **TITULAR** e preencha os dados solicitados.
3. Use o botão **PRÓXIMO** para avançar até **NOTAS** e **INFORMES**.
4. Preencha cada etapa e confira o total na aba **INFORMES**.

## Tecnologias

- Microsoft Excel (fórmulas, formatação e botões de navegação)

## Observações

- Os dados presentes na planilha são apenas **exemplos**. Substitua pelas suas informações.
- Este app serve como ferramenta de organização e **não substitui** o programa oficial da Receita Federal.
